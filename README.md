# Посмотри в окно

Учебный проект третьего спринта курса фронтенд-разработки Яндекс Практикума. Приложение ищет видео по городу и времени суток, показывает список результатов и позволяет переключать видео.

Интерфейс оформлен с помощью HTML и CSS. Используются Flexbox, кастомные чекбоксы, состояния интерактивных элементов и локально подключённые шрифты. Логика приложения предоставлена в стартовом репозитории.

Для локального просмотра запустите из корня проекта `python3 -m http.server 8000` и откройте http://localhost:8000. Для загрузки видео необходим доступ к API Практикума.

Репозиторий проекта — https://github.com/sshpaakk/posmotri-v-okno-ad
